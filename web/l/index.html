Get the log

    
With a phone: on the board, open ☰ → Settings → Diagnostics → Send Log and point your phone's camera at the QR code. This page opens with the log.

    
With a computer (Chrome or Edge): plug the board in by USB and read the whole log:

    
This browser can't talk to USB devices. Use Chrome or Edge on a computer, or the QR code on the board.

    

    

    
Pick the board's serial port when asked (the same one used to install). If none appears on Windows, install the CH340 USB driver.
