CYD Classic Games

Chess, checkers, solitaire, Sudoku and many more classic games for the ESP32 "Cheap Yellow Display". Install it on your board straight from this page.

 

Kid-safe

Made to be safe for kids and still fun for grown-ups, like LEGO. No ads, no accounts, no internet. Two boards can play each other nearby, but players can't chat or send messages: only game moves and fixed answers like "Play" or "No Thanks" travel between boards.

Install

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer to install.

  1. Use Chrome or Edge on a computer (Windows, Mac, Linux or a Chromebook). Installing needs the browser to reach USB, which Chrome and Edge can do and most other browsers (Firefox, Safari, phones) can't.
  2. Plug the board into the computer with a USB cable that carries data (some cables only charge).
  3. Pick your board in the list below and click Install. Choose the serial port that appears. None on Windows? Install the CH340 USB driver and try again.
  4. Wait for "Installation complete", then press the board's reset button (or unplug it and plug it back in).
Installing needs Chrome or Edge on a computer. Installing needs a secure (https) page.

The games

The board starts on a game picker, grouped by kind of game, and reopens your last game in one tap. Two-player games play against the computer (three levels), pass-and-play on one board, or wireless against another board nearby.

After installing

  • Touch calibration runs on the first start: tap the tip of each corner arrow. To redo it later: Settings (the gear) → Touch → Recalibrate, or hold the BOOT button while powering on.
  • Colors look wrong? Settings → Display: Invert Colors if colors look like a photo negative, Swap Red/Blue if red and blue are swapped. The board remembers it.
  • Blank or garbled screen on a 2.8" board? It has the other display driver: install the other 2.8" version.
  • Playing a friend's board: Settings → Play → Play Mode 2P on both boards, then Find Players. Both boards need the same version, so install them both from this page.

Something went wrong?

The board keeps a log of each start and any crash. To send it to the developer, open Settings → About → Send Log on the board and scan the QR code with your phone's camera, or plug the board in here and read the log over USB. Either way a page opens with the log, ready to email.
