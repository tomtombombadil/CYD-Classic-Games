Install

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer to install.

  1. Plug the board into your computer with a USB cable that carries data (some charge-only cables don't).
  2. Find your board below and click Install. Pick the serial port that appears. If none appears on Windows, install the CH340 USB driver and try again.
  3. Wait for "Installation complete", then press the board's reset button (or unplug and replug it).

After installing

  • Touch calibration runs on first start: tap the tip of each corner arrow. To redo it later, hold the BOOT button while powering on.
  • Colors look wrong? Tap Invert if the background is light or colors look like a negative, and Swap R/B if the red and blue bars are swapped. The board remembers the fix.
  • Blank or garbled screen on a 2.8" board? It probably has the other display driver. Install the other 2.8" version.

Something went wrong?

The board keeps a log of each start and any crash. To send it to the developer, open ☰ → Settings → Diagnostics → Send Log on the board and scan the QR code with your phone's camera, or plug the board in here and read the log over USB. Either way a page opens with the log, ready to email.
